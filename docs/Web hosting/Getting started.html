Getting started

How to add your domain

To get started with the web hosting you first need to add your domain.

  1. Login to your account here. Or incase that link dosen't work you can access it here.
  2. When logged in click on the "+ Add Web Domain" button.
  3. Enter the domain name / sub domain you want to add to your account.
  4. Press save when done.
  5. Where it says "Domain your.domain.here has been created successfully." click on your domain name.
  6. Here you can add any aliases you want, such www.your.domain or even other domains entirely.
  7. Goto the DNS manager of your domain(s) that you have added.
  8. Add one of the following dns records to your (sub) domain(s)

    • (Recommended) Add the following record to have IPV6 support. If you experience any issues with the SSL certificate generation please use the other record.

      Type: CNAME
      Content: web.summergrid.com

    • Please note this record is not recommended as it does not support IPV6. Only use it if you have issues with the first one.

      Type: A
      Content: 209.50.255.250
  9. Go back to the SummerGrid web hosting panel.
  10. Enable the "Enable SSL for this domain", "Use Let's Encrypt to obtain SSL certificate", and "Enable automatic HTTPS redirection" toggles.
  11. You may optionaly enable the enable domain redirection toggle to use either the domain or a specific alias.
  12. Click the "Save" button at the top right. Please wait up to 1 minute for the system to generate your SSL certificate.
  13. Done! Your site is now live on SummerGrid web hosting.

How to put something on your website

Using the quick installer

Want to quickly setup a wiki, personal cloud, wordpress site, or more? Use the quick installer to get started fast.

  1. Select the domain you wish to install the app on.
  2. Click on the "Quick Install App" button at the top right.
  3. Select on any app you wish to install and press the "Setup" button.
  4. Fill in all of the details and press the "Save" button.

Using the file manager

Want to edit the source code of your website or build your own app using your own code? Use the file manager for full control over your website.

  1. When signed into your web hosting control panel click on the folder icon at the top of the page.
  2. Navigate to your website folder (web > your.domain > public_html)
  3. You can now edit all your source code on your website.
    Our web server supports .htaccess files. Want to edit your error pages (404, 500...)?

    Navigate to the web > your.domain > document_errors and edit the html files there.
