How to secure your VPS account

When you first get your VPS, it comes with a default password. It is important to change this password to secure your server.

Changing your VPS password

  1. Connect to your VPS via SSH.
  2. Use the command passwd to change your password. You will be prompted to enter your current password and then your new password twice for confirmation.
    Make sure to choose a strong password that includes a mix of letters, numbers, and special characters to enhance security.
  3. After changing the password on your account make sure to also change the password on the root account. To do this, use the command sudo -s and enter your password.
  4. Then, use the command passwd again to change the root password.

Changing your username

When you first get your VPS the default username is summergriduser. For added security + ease of use it is recommended to change this.

  1. Connect to your VPS via SSH.
  2. Access the root account using the command sudo -s and enter your password.
  3. Enter the command useradd -m -G sudo tempadmin to add a temporary admin user to use for this process.
  4. Enter the command passwd tempadmin and set a password for the temporary admin user.
  5. Log out of your current session by entering exit 2 times until you are disconnected from the SSH session and then log in as the temporary admin user using SSH ssh tempadmin@your_vps_ip.
  6. Now enter the command sudo -s and enter the password for the temporary admin account.
  7. Now run the command pkill -u summergriduser (Replace summergriduser with the old username if it is different.) to log out the orignal user.
  8. Use the command sudo usermod -l new_username -d /home/new_username -m summergriduser (Replace new_username in the command with the username you want and also replace summergriduser in the command with the old username if it is different.)
  9. Now run the command sudo groupmod -n new_username summergriduser (Replace new_username in the command with the username you want and also replace summergriduser in the command with the old username if it is different.)
  10. Now run exit 2 times until you disconnect from the SSH.
  11. Now login to your SSH via your new username and original password.
  12. Now enter the root account by entering sudo -s and enter your password.
  13. Now run the command pkill -u tempadmin to log out the temporary user.
  14. Now delete the temporary admin account by entering the command userdel -r tempadmin.
  15. Now it is recommended to either reboot the system with the command reboot or to close the SSH and reconnect.
