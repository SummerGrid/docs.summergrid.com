How to expand your VPS's root drive

Purchased a large storage option for your VPS however only seeing 5GB? This guide will show you how to extend your root drive so you can use your entire allocation!

Allocated sizes might differ from reported sizes because of conversions and system partitions.
  1. Connect to your VPS's SSH server.
  2. Access the root account by entering sudo -s.

    You will need to enter your credentials again to access this command. You will know when you have done this correctly as your terminal will say root@... at the start of your line.

  3. View all storage devices connected to your VPS by running lsblk.

    This will display a list of all storage devices.

    The drive you will need to use will usualy be at the bottom of the list and named xvdb or similar. It should have no partitions listed below it.
  4. Now we need to create a partition on the new drive. Run fdisk /dev/xvdb (replace xvdb with the name of your new drive if different).

    This will open the fdisk utility for the new drive.

    In this utility enter n for the command (This will create a new partition).

    Next enter p to select a primary partition type.

    Then press Enter to accept the default partition number.

    Press Enter again to accept the default first sector.

    Finally press Enter one last time to accept the default last sector.

    Now enter t to change the partition type.

    Enter 8e to set the partition type to Linux LVM.

    Finally enter w to write the changes to the disk and exit the utility.

  5. Now enter pvcreate /dev/xvdb1 (replace xvdb with the name of your new partition if different) to initialize the new partition as a physical volume for LVM.
  6. Now enter vgs.
    This will display the volume groups on your system, including the one you want to extend.

    Make a note of the name of the volume group you wish to extend, usually SummerGridDefault-debian-vg or similar.

  7. Now enter vgextend SummerGridDefault-debian-vg /dev/xvdb1 (replace SummerGridDefault-debian-vg with the name of your volume group and xvdb1 with the name of your new partition if different) to extend the volume group with the new physical volume.
  8. Now enter lvextend -l +100%FREE /dev/SummerGridDefault-debian-vg/root (replace SummerGridDefault-debian-vg with the name of your volume group if different) to extend the logical volume to use all available free space.
  9. Now enter resize2fs /dev/SummerGridDefault-debian-vg/root (replace SummerGridDefault-debian-vg with the name of your volume group if different) to resize the filesystem to use the extended logical volume.
  10. Now to confirm that this has worked enter df -h / which will show you your updated root drive size.
Done! You have successfully expanded your VPS's root drive to use the full allocated storage size.
