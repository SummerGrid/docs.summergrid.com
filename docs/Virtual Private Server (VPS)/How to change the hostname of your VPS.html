How to change the hostname of your VPS

When you first get your VPS, it comes with a default hostname that you might want to change to something more recognizable or appropriate for your use case.

  1. Connect to your VPS via SSH.
  2. Access the root account by entering sudo -s.
    You will need to enter your credentials again to access this command. You will know when you have done this correctly as your terminal will say root@... at the start of your line.
  3. Enter the command hostnamectl set-hostname your.hostname-here.com. Replace your.hostname-here.com with the desired hostname for your VPS. This will change the hostname of your VPS.
  4. Next you need to edit the hosts file. Todo this enter the command nano /etc/hosts.
    Here you will see multiple lines. Look for the line that says # The following lines are... above that line enter 127.0.1.1 your.hostname-here.com Replace your.hostname-here.com with your actual hostname.

    Save and exit the file by pressing Ctrl + S to save and then Ctrl + X to exit.

  5. Reboot your VPS to apply the changes by entering the command reboot.
